# Excel / CSV Privacy Cleaner — Windows

CSV・XLSXの指定列をマスキング、仮名化、または削除して、新しいコピーを作るローカルツールです。

**最短操作:** ファイルを選択 → 処理したい列をチェック → mask / pseudonymize / drop から選択 → 数行の処理前後をプレビュー → 新しいファイルへ出力。詳細設定は通常は閉じています。列を1つも選ばない場合は出力できません。

検査対象の列を選ぶことと、ブック全体から機密情報が消えたことは別です。未選択列、数式、画像、非表示構造、外部リンクなどに情報が残る可能性があります。プレビューは数行の参考表示で、実際の出力の安全性を保証しません。複雑なExcel構造やマクロ付きファイルは保証対象外です。

元ファイルと既存の出力ファイルは上書きしません。仮名化のキーは起動時にランダム生成され、継続して同じIDへ変換するにはご自身でキーを保持する必要があります。

テスト方法とMicrosoft Store販売ゲートは [WINDOWS.md](WINDOWS.md) を参照してください。**販売判定：HOLD**。

## UI安全性の追加改良（2026-10-19）

`ui/safe-product-upgrade-20261019`では**プレビューの承認を元データSHA-256・選択列・処理方法・仮名化キー・非表示シート/コメント設定へ固定**しました。変更後は再プレビューが必須です。承認は出力1回で消費されます。生成時に原本が変わった場合は新しい出力ファイルを破棄します。既存のCSV/XLSX処理、構造拒否、式検査は維持。

これにより完全な匿名化ができるようになったわけではありません。マクロ、式、画像、隠しシート、外部リンク等の対応・未対応を明示し、出力後の人手確認が必要です。
