# Microsoft Store 日本語商品情報（提出前ドラフト）

**掲載名候補**: Excel / CSV Privacy Cleaner
※実際の名称予約および商品ID・正式価格はPartner Center未確認。

## 短い説明
CSV・Excelの指定列を、チェック操作でマスク・仮名化・削除。ローカルで新しいコピーを作成。

## 詳細説明
外部委託先へ顧客一覧を送る前や、会議・検証用にデータを加工するとき、必要な列だけを選んで変換できるWindowsアプリです。元ファイルを変更せず、用途に合わせたコピーを出力します。

**使い方**: ファイルを選ぶ → 加工したい列にチェック → マスク／仮名化／列削除を選ぶ → プレビュー → コピーを保存。

特徴:
- CSV・XLSXに対応。日本語列名をチェック方式で選択
- メールアドレス候補をマスク、任意の列を仮名IDへ変換、不要列を削除
- 入力ファイルおよび既存の出力ファイルの上書きを拒否
- 対応するXLSXの非表示シート・コメント・一部の外部リンクを処理
- CSVの数式実行リスクが残る場合、出力前にブロック
- 日本語・英語UI。通常操作は簡潔にし、詳細設定は折りたたみ

**容量上限**: CSVは25MiB、XLSXは圧縮時15MiBかつ展開対象160MiB、データは原則10万行/シートまでを対象とする開発版仕様です。大容量データは対象外です。

**重要な制限**: 本製品はファイル内の全ての個人情報を発見・削除するサービスではありません。未選択の列、数式・画像・図表・埋め込みオブジェクト、複雑なExcel構造は完全に監査されません。仮名化は暗号化・匿名化ではありません。出力を外部共有する前にご自身で確認してください。マクロ有効形式XLSMは未対応です。

3. 加工前後プレビュー（架空の顧客のみ）
4. 出力完了と限界説明の表示
架空のデータのみを使用。個人ファイル・メール・画面上の秘密情報を載せない。Windows 10/11と100/125/150% DPIで余白、文字切れ、コンボ表示を確認。
